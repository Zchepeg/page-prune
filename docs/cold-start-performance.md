## 已实现但默认关闭的异步模式

runtime.defer_model_startup默认false，原服务配置未改。开启后，首次需要模型时在单个后台任务中加载与预热，前台返回model_starting不确定状态；只预热有限微批量及单样本路径，不创建训练进程。规则路径继续执行。

模型状态新增idle/loading/warming/ready/failed、加载与预热耗时、仅错误类型的诊断；失败后30秒内不重复加载。同步CLI调用仍保留兼容。启动等待不写决策缓存、不形成训练样本，准备好后才进行正式决策。后台预热耗时与候选模型批次计时分开，不能把等待结果算作已完成模型判断。

扩展现在对model_starting及model_budget成功响应安排约2秒后的有界重扫，清除对应扫描指纹，避免不再重试；不把等待状态送入探针分析。连接失败仍沿用原30秒重试设置。每个响应批次合并一个延后定时器，单次扫描仍受80候选限制。

这将加载工作移出首次请求等待路径，不减少模型本身加载或GPU计算成本。等待期间模型灰区默认保持页面不变，可能暂时显示广告；规则与静态网络拦截不受影响。新行为尚未在正式浏览流量中启用，未声称真实P95已经下降。

## 自身隐藏引起重复扫描的修复

已定位到隐藏前指纹与隐藏后尺寸/可见性不一致。统一隐藏入口在修改display后同步更新scanState，避免自身style变化再次提交；重复隐藏也不再覆盖最初的display恢复值。没有跳过所有隐藏元素，页面主动显示目标后仍会重新判断，人工标记使用同一入口。

隔离测试增加了稳定期和主动恢复检查。20秒加载等待测试中，目标首次隐藏后不再重复提交；65秒稳定期跨两个30秒全量扫描周期，目标保持仅一次隐藏判断，主动显示后才收到第二次隐藏判断，原display值保留。正常对照元素与断线放行均通过。此结论针对受控目标，隐藏引起的父容器布局变化仍可能是需要重新判断的真实输入变化。

结果为`runs/performance-async-v1/e2e-no-self-rescan.json`和`e2e-steady-65s.json`。这次修改只更新源码，正式浏览器现有内容脚本需要扩展重载和网页刷新后才能使用；未自动操作用户浏览器或重启服务。
