# JEV-Ad Decision Protocol v1

JEV-Ad Decision Protocol v1 是本项目在确定性广告规则、Qwen 决策器与执行策略之间定义的稳定契约。协议版本为 `jev-ad-decision-v1`。

## 输入

每个候选元素只携带经过裁剪和脱敏的页面域名、元素类型、短文本、标识符、有限属性、去除凭据与查询参数的资源 URL、尺寸及可见性。整页 HTML、Cookie、表单值和 URL 密钥不属于协议输入。

确定性检测器输出：

- `score`：范围为 0 到 1 的规则置信度；
- `route`：`block`、`allow` 或 `jev`；
- `evidence`：可审计的规则证据集合。

Qwen 决策器输出：

- `verdict`：`block`、`allow` 或 `uncertain`；
- `ad / non_ad` 语义概率；旧检查点也可以返回显式证据不足概率；
- 校准档位、模型版本和诊断信息。

新检查点不把证据不足当作内容类别。语义概率低于置信度门槛、类别间隔不足、输入截断或规则冲突时，决策器生成 `uncertain`。

## 路由

| 条件 | 路由 | 行为 |
| --- | --- | --- |
| 高置信规则结果 | `rule` | 不调用模型，保持低延迟 |
| 规则灰区 | `model` | 由 Qwen 决策 |
| 接近规则阈值的明确结果 | `challenge` | 调用 Qwen 验证规则结论 |

`challenge_block_below` 和 `challenge_allow_above` 控制挑战区间。`challenge_rule_blocks` 只有在候选模型通过独立晋级门槛后才启用；默认关闭时，规则阻断不会被未验证模型降级。已知广告主机等置信度为 1 的事实仍走规则快速路径。

## 合议

挑战路径中规则与模型同意时，结果标记为 `rule_model_consensus`。两者给出相反结论，或模型返回证据不足时，协议将最终结论降级为 `uncertain`，交由风险策略 fail-open 或复核，不允许冲突结论直接执行不可恢复阻断。

每次冲突写入脱敏的 `data/events/disagreements.jsonl`。记录包含规则分数、证据、规则结论、模型结论、冲突类型和协议版本，不保存候选文本或页面 HTML。

## 主动学习

待复核优先级由三个独立量组成：

- 规则与模型是否冲突；
- 模型概率间隔和 `uncertain` 概率反映的不确定度；
- 样本与规则边界的距离。

冲突样本优先级最高，其次是高不确定度和规则边界样本。主动学习只决定是否进入无标签复核队列，不会把模型输出直接写成训练标签。只有确定性强规则样本或人工确认样本能够进入训练源。

## 输出边界

协议只产生决策，不直接操作页面。最终的 `block`、`hide`、`allow` 或 `review` 仍由独立策略层根据受保护元素、概率阈值、校准档位与 fail-open 设置决定。
