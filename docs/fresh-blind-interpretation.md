# 新盲测结论与成本取舍

2026-11-01 完成评测。推理前冻结了 36 个新域名的 352 条人工标签，其中广告 69 条、非广告 283 条。模型、阈值、输入和规则资产通过完整性校验，表中列出全部预登记候选。

## 统计解释

每项比较使用36域名配对聚类bootstrap，10000次、种子42。动作广告召回差值95%区间分别为：轻量[11.27,36.49]、Qwen v2种子42[17.86,44.23]、v2种子7[23.53,54.69]、v3种子42[30.14,58.75]、v3种子7[14.29,42.86]个百分点。

五个区间均高于零，说明这批候选上的动作召回有所增加。区间按候选分别计算，未做多重比较调整，也未计入训练随机性。

轻量级联在 283 个非广告候选中没有误杀。按候选独立计算，Wilson 95% 上界约为 1.34%。按域名重采样的误杀率差值另见聚合报告。

## 为什么仍不升级v3或自动部署Qwen

种子 42 从 v2 换到 v3 后，处理的广告从 56 条增到 66 条，误杀从 1 条增到 5 条。种子 7 的变化方向相反，处理的广告从 62 条降到 54 条，误杀从 3 条降到 2 条。两组结果不足以估计训练方差，也缺少支持升级 v3 的一致证据。

只看 73 次模型调用，轻量模型 P95 为 0.671 ms，四个 Qwen 候选分别为 95.483、93.923、102.569 和 95.173 ms。上表的决策核心 P95 则以全部 352 条候选计算。

轻量模型在 CPU 上运行，压缩文件为 246,232 字节。Qwen 进程已分配约 2,620 MiB 显存，保留约 4,084 MiB。本轮 Qwen 加载约 12.8–22.3 秒，轻量模型约 1.40 秒。加载时间受页缓存、运行顺序和机器负载影响。

Qwen 多找回的广告伴随额外误杀和 GPU 开销。轻量级联随后进入[真实网页影子观察](lightweight-shadow-validation.md)，本轮评测结束时继续使用原部署检查点。

## 纯模型诊断与历史结果的关系

无规则证据的纯模型诊断中，四个新Qwen分类识别广告分别41、55、61、45条，最终动作分别21、53、59、27条；动作误杀分别0、2、2、0条。这说明这些新候选在本数据集上并非零召回，但不能把它与旧检查点在另一批490条样本上的零召回直接相减，或只归因于某一种训练改动。

Qwen纯模型诊断有12～13条截断，需与概率和策略拒绝一起分析。新集包含混合候选抽样、公开站点可访问性偏差和截图缺失记录，不代表自然网页广告比例，也不测量浏览器静态网络规则的整体拦截率。

## 复现与保存

入口为`scripts/evaluate_fresh_blind.py`与`scripts/summarize_fresh_blind.py`。每个候选独立进程运行，NF4、384 token、微批配置2，实际评测为串行单候选、无缓存。只在启动前做有限预热，不修改校准温度。候选按既定顺序执行，GPU在线服务保持驻留，故延迟不是独占GPU的严格基准，更不是HTTP或浏览器整页延迟。

评估器在标签冻结后、预测前完成并记录哈希。测试覆盖原生 v3 输入、证据清空和规则分流。纯规则模式的模型调用次数为 0。

公开聚合表和区间保存在 `artifacts/evaluation-fresh-blind-v1/`。逐条预测及本机记录见 `runs/fresh-blind-review-v1/evaluation-v1/`。评测时的回归测试通过 188 项。

评测期间，在线服务收到 3 个请求和 3 条候选，模型调用和请求失败均为 0。评测进程退出后，显卡占用回到约 4,270 MiB，可用约 7,675 MiB。这次在线观察仅覆盖上述请求。

该盲测今后若用于模型、输入、规则或阈值选择，就应转为开发资料，下一版本需新冻结数据，不能反复宣称独立盲测。
