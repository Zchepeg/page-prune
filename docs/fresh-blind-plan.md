# 新候选模型的冻结盲测准备

日期：2026-11-01。此阶段只准备评测，不训练、不部署、不生成机器标签，也不把新池用于调参。

## 冻结对象与比较问题

已在采集前登记Qwen v2/v3各两个训练种子（42、7）和字符TF-IDF逻辑回归，共五个候选。模型文件、任务与输入相关代码、策略阈值及检测参数都有哈希记录。主问题是每个候选相对纯规则的页面动作广告召回与非广告动作误杀；分类指标、覆盖率、校准、调用率和成本另报。

各模型使用自身原生输入版本和已保存校准，不在盲测上挑温度、种子、输入或动作阈值。五项候选比较先作为描述性结果；如作显著性主张，还须处理多重比较。域名聚类bootstrap反映域名抽样，不包含训练种子不确定性。

## 采集与来源

排除历史训练、校准、评测及采集池识别出的665个域名，另检查重定向后的域名与父子域名匹配。该检查不等价于完整公共后缀或组织独立性判定。预先固定99个可尝试站点的顺序，各域名最多取10条，混合可疑、正常对照、中性和模糊候选。

原方案保存为`runs/fresh-blind-v2/plan.json`，按420秒预算采集。因站点超时或拒绝访问，后续在无标签、无模型预测时登记固定未访问中段与尾段补充批次。原计划保留，不覆盖；补充选择仅依据未标注的数量与访问进度，不依据类别或模型表现。合并保留所有不重复域名，重复域名按首批优先，不根据标签筛选。

最早的`fresh-blind-v1`在任何采集前因盲标界面冻结参数修复而废弃，保留SUPERSEDED记录，不作为实验批次。

采集使用临时匿名浏览器，不加载用户账号或正式扩展，不访问正式决策API。候选截图和脱敏结构保留本机，HTML字段在入池时清空。采集期间不执行候选模型；正式服务无需重启，也不会额外加载Qwen争抢显存。

## 人工标注与冻结门槛

人工标注时隐藏全部机器建议，只标广告、非广告或证据不足。不得把本助手的判断写成`human_independent`。整个待评池需要独立人工复核；证据不足保留记录，二分类冻结时排除并披露数量。

原有正式门槛保持不变：至少300条二分类人工记录、30个域名，广告与非广告各至少50条。未达到时状态为待补充，不能为了出结果放宽门槛或把小规模试验改称正式盲测。

`scripts/freeze_fresh_blind.py`负责验证模型、代码、截图与候选池哈希，检查历史域名排除及全池独立人工复核，拒绝覆盖已经冻结的基准。规则JSON资产在无标签合并时另行冻结，明确晚于初始采集登记、早于标签与推理，不伪称所有资产均在采集前登记。

正式推理必须等待人工标签冻结与资产校验通过。未经新评测，不提升任何候选为默认模型。新盲测一旦被用于后续选模型或调参，就不能继续作为下一版本盲测。

## 工具

- 方案与无标签采集：`scripts/prepare_fresh_blind.py`。
- 按预登记来源合并并固定截图：`scripts/merge_fresh_blind.py`。
- 本地盲标页面：`scripts/review_evaluation_pool.py --blind --independent-only --ground-truth-task binary_ad_detection`。
- 全池完整性校验与最终冻结：`scripts/freeze_fresh_blind.py`。
- 后续配对统计：`evaluation/paired_statistics.py`，逐样本数据只留本机。

页面冻结与命令行现已统一传递二分类及独立标注参数；机器辅助标签与证据不足不进入二分类基准。新盲测最终使用额外完整性门禁；界面生成的预览不能代替该门禁。

## 合并后的使用方式

统一候选池使用`runs/fresh-blind-review-v1/`。在项目环境中启动：

```powershell
python scripts/review_evaluation_pool.py --pool runs/fresh-blind-review-v1/pool.jsonl --annotations runs/fresh-blind-review-v1/annotations.jsonl --output runs/fresh-blind-review-v1/review-preview.jsonl --metadata runs/fresh-blind-review-v1/review-preview.metadata.json --port 8892 --blind --independent-only --ground-truth-task binary_ad_detection
```

打开终端显示的本地链接，按1标广告、2标非广告、3标证据不足。图片缺失、空白或结构线索不足时，不要为了数量猜测标签。全部标完后执行最终冻结：

```powershell
python scripts/freeze_fresh_blind.py --directory runs/fresh-blind-review-v1
```

该命令会拒绝未完成的独立复核、低于原有数量门槛或资产哈希变化；只有通过后才生成`benchmark.jsonl`与元数据。此前不会声称新模型通过了盲测。
