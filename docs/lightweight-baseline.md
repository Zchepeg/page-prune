# CPU轻量分类基线与Qwen成本对照

日期：2026-11-01。固定使用同一326条人工训练、155条校准及153条开发验证（25广告、128非广告）。没有搜索验证集参数，也没有修改部署。

## 方法

字符TF-IDF使用char_wb、3至5字符、min_df=2、最多20000特征；逻辑回归C=1、liblinear、最多1000次迭代、种子42。训练将每条状态复制为有规则证据和无规则证据两种，各占一半样本权重，按域名频次的-0.5次方加权。校准仅使用155条校准数据，固定温度网格0.05至20，拟合温度0.3892。

输入与Qwen的v2候选状态相同，轻量模型不使用任务说明，也没有384 token截断；Qwen仍使用384 token上限。两者优化器、正则化、标签平滑与训练过程不同，属于方法与成本基线，不是只改变一个训练变量的消融。页面策略与选择性阈值相同；实验中按与Qwen相同档位模拟动作，并不构成可部署校准认证。

## 成本实测

训练向量化与逻辑回归拟合约272毫秒，不含进程启动、导入与校准；压缩模型文件246232字节，约240KiB。模型文件含训练词表，继续只保存在runs，不作为公开无隐私资产。文件大小不是进程内存占用，本轮未测完整CPU进程内存峰值。

延迟在独立进程中使用相同前20条验证状态，3次预热后重复3轮，共60次串行单样本调用，仅测后端：

| 后端 | 平均 | P95 | 加载含后端导入 | 显存 |
| --- | ---: | ---: | ---: | --- |
| CPU TF-IDF | 0.502 ms | 0.606 ms | 约1.19秒 | 不需要 |
| Qwen v2种子7、NF4 | 82.934 ms | 91.752 ms | 约21.19秒 | 已分配约2620MiB、保留约4084MiB |

数据预读在计时外，加载不含整个Python进程启动。比较不包含服务、缓存、批处理、浏览器或页面动作；仅20条状态，不能外推网页整体提速倍数或高并发吞吐。

## 决策

轻量模型提供了明确的低成本参考，但本次召回及误杀未达到Qwen较好候选的开发表现；Qwen仍存在训练种子波动。因此保留规则快速路径与两种实验后端，不默认替换。下一步可离线验证轻量模型是否适合高置信正常样本预筛选或复核排序：必须在校准数据固定筛选规则，并在留出数据报告漏放广告、减少Qwen调用比例及动作误杀，不能直接上线多级路由。

全部结果仍来自反复使用的开发数据，不是新独立盲测。复现依赖requirements-baseline.txt；训练脚本scripts/train_lightweight_baseline.py；后端jev/lightweight_backend.py尚未注册为服务默认后端；延迟脚本scripts/benchmark_decision_backend.py。模型、逐样本报告及两份性能报告位于runs/tfidf-baseline-v1。

后续预筛选验证已完成，见lightweight-prescreen.md：校准灰区没有可接受的高置信放行阈值，预筛选未启用，当前不增加该级联层。
