# 轻量级联的页面安全与影子验证

2026-11-01 在临时浏览器配置和独立本地服务中测试轻量模型。

## 1. 页面动作验证

用冻结的 TF-IDF 检查点走一遍扩展的配对、判断和执行流程。正文可读，页内导航和表单提交正常，视频控件也保留。视频检查仅覆盖控件显示。

首轮测试期望隐藏合成的 Sponsored 卡片。模型给出的广告概率是 0.5017，策略判为不确定并放行，因此测试失败。原始结果保存在 `runs/lightweight-page-safety-v1/`。

随后分别验证两条执行路径。真实模型放行时，页面保留卡片。测试夹具对合成目标返回固定的 0.97 后，扩展能隐藏元素、保留原 `display`，并在服务关闭后恢复显示。固定输出仅用于执行测试。两次结果分别保存在 `runs/lightweight-page-safety-v2/` 和 `runs/lightweight-page-action-fixture-v1/`。

## 2. 影子路径实现

`runtime/lightweight_shadow.py`提供独立后台观察器，不产生页面命令，不写训练标签或默认持久化原始候选。它只接收规则灰区，主路径仍返回原有规则动作；本轮未注册为正式服务后端，也未增加线上服务开销。

预算包括：单后台线程、队列64项、状态哈希去重最多512项、去重TTL900秒、排队超过30秒丢弃、延迟窗口512项。队列满时直接丢弃，不等待模型；异常仅记录类型，不把错误文本带入统计。关闭时停止接收新任务并有界等待已有任务。

可选回调只在隔离采样工具中收集有限潜在新增动作，复核材料留在`runs/`，不进入训练。回调异常与模型异常分别计数，不影响主路径。浏览器采样每页最多保留5条复核材料，内存复核队列最多100条；没有声称保留全部分歧。

四项针对性测试覆盖主动作不变、统计不泄露原文、队列有界、去重、异常隔离、受保护元素、回调失败和关闭后拒绝新任务。全项目192项测试通过，8.60秒。

## 3. 匿名公开页面运行

以同样顺序尝试6个公开页面，使用临时匿名配置，不复用用户账号。基线轮只执行纯规则，影子轮也只执行纯规则，但后台计算TF-IDF建议。每轮均有扩展静态规则，因此不是“无任何屏蔽”的浏览器对照。

| 项目 | 规则基线轮 | 规则＋影子轮 |
| --- | ---: | ---: |
| 访问成功页面 | 5/6 | 6/6 |
| 候选命令 | 138 | 223 |
| 主路径请求 | 11 | 15 |
| 主路径平均编排耗时 | 0.702 ms | 0.837 ms |
| 主路径P95 | 3.012 ms | 3.606 ms |
| Python进程结束RSS | 47.934 MiB | 142.652 MiB |
| Python进程CPU时间 | 0.21875 s | 0.21875 s |

影子轮：212条明确候选跳过，8次重复跳过，实际排队并处理3个唯一灰区；建议放行2个、隐藏1个。队列丢弃、过期、输入错误、模型错误及回调错误均为0。轻量新增动作发送到浏览器为0。

唯一潜在新增隐藏的概率约0.7485，结构类名像广告容器，但复核截图为空白，页面当时仍保持可见。没有足够证据把它标为确认广告、误杀或成功拦截；标签保持空缺。该复核不计作独立人工真值，也未更改已有352条冻结标签。

网页动态内容、访问成功数和候选数不同，因此两轮P95差值不能被解释成影子路径因果开销，也不能用CPU百分比下降宣称性能改善。

## 4. 成本口径

影子轮Python进程在模型初始化前RSS约39.270MiB，初始化后135.906MiB，增加约96.636MiB，运行峰值约142.848MiB。增量包含scikit-learn等依赖和模型，不是纯权重大小；不包含浏览器及驱动子进程，也不代表整机内存占用。

模型与观察器初始化约1.209秒。59.37秒观测中Python进程CPU时间约0.219秒，折算单核等效平均约0.37%；此处也包含HTTP与驱动线程。只有3个影子判断，平均3.689ms、P95为8.435ms，样本不足以评价稳定P95；它也不同于此前充分预热的离线0.671ms调用P95。

影子线程CPU计时显示0ms，反映短任务下Windows计时分辨率等限制，不能解释为计算免费。模型文件约240KiB也不能等同于进程仅占240KiB内存。

## 5. 接入决定

本轮保留独立影子工具。三个真实网页灰区里，唯一建议隐藏的元素只有一张空白截图。是否提供 CPU 执行模式，要等更多带页面上下文的隐藏建议完成人工复核后再决定。

## 6. 复现与本地文件

运行前需要本地冻结的 TF-IDF 检查点和评测方案。模型含私有训练词表，因此仅保存在本地。

```powershell
python scripts/lightweight_page_safety.py --output runs/lightweight-page-safety-new
python scripts/lightweight_page_safety.py --force-action-fixture --output runs/lightweight-page-action-fixture-new
python scripts/run_lightweight_shadow.py --baseline-only --output runs/lightweight-browser-baseline-new
python scripts/run_lightweight_shadow.py --output runs/lightweight-browser-shadow-new
```

脚本拒绝覆盖已有目录。复核截图与有限状态在影子目录内，其`human_label`仍为空；不提交到公开仓库。聚合结果另保存在`artifacts/lightweight-shadow-v1/summary.json`，不含网页内容、域名或本机文件路径。
