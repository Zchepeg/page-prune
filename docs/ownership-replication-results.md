# 随机种子重复与恒定字段控制

日期：2026-11-01。目的：检验此前v3优势是否稳定，以及是否必须依赖真实资源归属值。

新增三组实验在运行前固定于runs/ownership-replications-v1/plan.json：种子7的v2、种子7的v3、种子42的v3恒定字段组。结合既有种子42的v2/v3，共五个候选；未按成绩丢弃任何组。

训练均为326条、37域名、两轮、50%证据丢弃；最佳轮次按原99条早停验证选择。均使用155条人工校准、153条开发验证（25广告、128非广告、10域名）。恒定组在训练、校准和评估均将自身资源置空、归属标记置未知，保持同样的v3字段结构。样本、标签、切分、其他特征一致，不以验证成绩选种子。

## 结论与决策

1. 原单次训练优势未稳定复现，不能把v3作为默认输入升级或宣称新字段提升。
2. 恒定字段控制在种子42下复现了相近表现，真实资源归属值不是本次高分的必要条件。这与固定检查点输入消融结果一致，但未进一步确定是token排布、优化轨迹或其他机制导致差异。
3. 所有结果来自反复使用并追加采集的开发数据，不替代新的独立盲测。域名bootstrap仅描述该开发集的域名抽样不确定性，不包含训练随机性。
4. 不部署任何候选，不按当前成绩挑选最佳种子或阈值；现有默认输入和服务配置不变。v3作为实验和审计表示保留。

下一阶段应优先建立稳定性与成本对照：冻结现有开发数据和预先声明的种子列表，加入简单结构/文本分类基线，检验4B模型是否提供足够额外价值；对有重复价值的候选再做新域名盲测和浏览器动作验证。新增人工样本优先覆盖广告标记与正常导航/推荐的混淆，而不是继续扩充未经验证的输入字段。
