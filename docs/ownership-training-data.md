# v3资源归属训练数据

目标是为candidate-features-v3取得具有真实资源归属信息的人工监督。旧人工训练294条归属未知；新308条已固定为校准和开发验证，不转为训练。

本轮从新生活、设计、资讯及电子技术域名采集，排除全部训练来源、训练快照、两版旧人工基准与所有calibration前缀采集池的域名及父子域名。使用临时未登录Edge配置，最多96条、每域名最多8条。候选与截图保存在runs/ownership-training-capture-v1，角色为训练用途候选，不属于新独立评测。

审计区分已知自身资源、已知无自身资源与归属未知；空自身资源列表在归属已知时不能解释为缺失数据。截图缺失或视觉内容不足的记录需要人工选择证据不足，不能凭广告类名直接确认标签。

人工标注后仍需按域名排除校准和验证数据、核对类别与来源覆盖，再决定能否与旧人工训练数据混合。新模型必须记录输入版本，并完成训练、校准与推理的一致性检查；不能把v3输入直接提供给旧模型后引用其旧评测。

训练权重、校准参数、阈值与正式服务配置在采集阶段均不改变。

## 首批实际结果

原整批采集出现单页面长期阻塞，核验命令行身份后只停止本次采集进程32188；原目录保留一张未完成采集的截图，没有训练样本。随后新增scripts/collect_bounded_training.py，每站点子进程最多30秒、总访问预算180秒，逐站保存状态与候选。超时与失败不计为有效样本。

限时任务保存32条、4个新域名于runs/ownership-training-bounded-v1：12条已知自身资源、20条已知无自身资源；规则高分3、低分23、边界6；25条截图有视觉变化、7条近空白。与既有训练、校准、验证及旧基准域名隔离检查通过。原96条目标未达成，此批不能据此宣称v3训练数据充足。

复核端口8881，标注文件runs/ownership-training-bounded-v1/annotations.jsonl。只确认当前截图或结构足以支持的标签，近空白与缺上下文时可选证据不足。复核完成后先检查广告/非广告及域名覆盖，再决定补采或构建受控训练对照，不自动训练。

## 人工标签与配对数据准备

32条全部独立人工复核：广告5、非广告27。与原294条人工训练合并后326条、37域名，其中广告84、非广告242。新资源归属监督目前仅32条、4域名、5条广告，不能据此认为v3有足够代表性。

scripts/prepare_ownership_training_pair.py生成ownership-paired-v1/v2和v3两个并行快照，保持相同ID、标签、域名、顺序、任务说明及原规则证据，仅归属字段与版本标识不同。原99条早停验证、90条校准的角色及域名保持原状。额外补充校准155条与验证153条未参与训练。源标注哈希与输出哈希存入manifest。

配对一致性检查通过。本轮仅准备数据，没有训练或修改正式配置。后续训练前必须确保检查点记录并校验输入版本，评价时使用真实已知归属的留出数据；旧99条/90条归属未知，不能单独证明新字段收益。
